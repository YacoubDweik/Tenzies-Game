# 🎲 Tenzies Game

(./Design.png)

This project is a simple implementation of the classic **Tenzies** game!  
Roll the dice until all boxes show the same number. You can "hold" (lock) dice to keep their value between rolls, aiming to match them all.

## 🕹️ How to Play
- Click **Roll** to roll all unheld dice.
- Click on a die to **hold** its value.
- Keep rolling and holding until all dice show the same number — then, you win!

## 🚀 Built With
- HTML
- CSS
- React

Enjoy matching them all! 🎉
